Constructive portfolio risk: progress

Latest completed work: fifth-phase system correctness. Start with SYSTEM_GUARANTEES.md for the flagship broker and trading statements. The canonical layout is in STRUCTURE.md; methodological sources are collected in REFERENCES.md.

Objective and scope

Develop a checked finite-scenario financial mathematics example over the library's higher-inductive Cauchy reals. Positive numbers represent losses; negative numbers represent gains. All probabilities, holdings, and losses may be arbitrary Cauchy reals, subject to explicit hypotheses.

The intended application combines portfolio aggregation, probability-weighted expectation, worst-case stress risk, and expected-shortfall certificates. A worked portfolio will demonstrate diversification and a certified risk budget. Economic equivalence will use a cubical set quotient, so duplicate financial representations have the same risk and acceptance properties.

Foundation discipline

  • Work stays in Cubical/HITs/CauchyReals/Example/Financial and its entry module.
  • The project enables --safe --cubical; no new axioms, postulates, holes, or weakened options are planned. Missing analysis would be an explicit theorem parameter, never a hidden assumption.
  • Finite maxima use constructive lattice operations, not decidable real order.
  • A real line segment is not a cubical equality path between distinct reals.
  • Existing untracked RealHomotopy and Spheres work is outside this task.

The third phase responds to the request for client FX swap portfolios and broker margin management. The working product assumption is a deliverable near/far FX swap, with both currency principals and ordered dates retained. Instrument cashflows and exact spot/discount-factor changes are being built locally. Further development: transaction costs, ambiguity, and sequential control

The next phase extends the checked foundation in three directions. Finite probability mixtures and their extreme-model risk bounds will represent uncertainty about probabilities. A coherent risk interface and two-stage composition will express sequential risk control. Proportional transaction costs will be included in losses rather than ignored by economic netting.

The practical targets are a robust allocation selected by an ambiguity set and a rebalancing example in which fees change the optimizer, including a proved no-trade regime at sufficiently high fees. New work continues to use safe Cauchy reals without missing-analysis postulates. Earlier results and their validation record below describe the completed first phase.

Checked finite risk foundation

Finite, Probability, Shortfall, WorstCase (initial core), EconomicEquivalence, ExpectedShortfall, and Portfolio have each passed agda-codex with exit code 0 and no holes, metas, constraints, or warnings. The finite layer includes finite Fubini, allowing expected portfolio losses to be computed from asset means. Allocation blending preserves nonnegativity and total capital. Asset-specific model errors produce an explicit reserve.

The expected-shortfall layer proves weak duality directly: if a probability vector Q satisfies Q_i ≤ κ P_i, then E_Q[L] ≤ t + κ E_P[(L-t)⁺] for every t. A matching primal/dual certificate proves a global minimum. IsCVaR records the global lower bound and propositionally truncated attainment; its value is unique. No general optimization or quantile existence theorem is assumed.

Cubical results include effective economic quotient paths, an equivalence with the image of the loss map using truncated fibers, univalence between these two presentations, and proof-independent risk certificates. Positive parts and stop losses preserve the native Cauchy-real closeness relation.

Current limits and useful next steps

  • Funding feasibility remains outside the fee model. Costs are additional same-horizon losses; they do not reduce target holdings.
  • The executable optimizer specializes to the supplied two-asset market. General certified rational linear programming and automatically produced approximation reports remain useful future work.
  • Probability ambiguity and fees are both developed, but there is no joint optimizer combining model ambiguity, transaction fees, and every policy constraint. The stress-constrained example combines fees and two controls.
  • Sequential risk uses fixed finite two-stage trees. General rectangular mixture results are upper bounds, not a full dual representation theorem; no generic multistage trading optimizer is claimed.
  • Execution classes describe current total loss. They need not retain the holdings information required to calculate later transaction costs.
  • No general arbitrary-real CVaR existence theorem is assumed, and no new analysis hypotheses were needed for any completed proof.

All changes remain in the requested example directory and its umbrella.
